# 雾散荆州｜荆楚文化探索网站

《雾散荆州》是一款以荆州历史文化为背景的探索游戏。本项目是围绕该游戏开发的独立文化展示网站，旨在通过网页介绍荆州文化、历史地标、游戏内容与互动体验。

## 项目功能

- **文化探索**：展示荆州历史文化与代表性地标。
- **游戏介绍**：介绍《雾散荆州》的背景与玩法。
- **多级导航**：支持首页、二级页面及三级页面跳转。
- **站内搜索**：使用原生 JavaScript 实现中文内容检索。
- **交互体验**：提供滚动动画、返回顶部及文化卡片交互。
- **在线游玩**：通过外部链接进入原游戏。

## 技术栈

- HTML5
- CSS3
- JavaScript（Vanilla JS）

本项目采用纯静态网站架构，不依赖前端框架、后端服务或数据库。

克隆项目后，可以使用 IntelliJ IDEA 或 VS Code 打开项目，通过本地静态服务器访问 `index.html`。
